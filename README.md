# Abejorro Digital: Tipografía

![Abejorro Digital Banner](https://github.com/user-attachments/assets/0aa67016-6eaf-458a-adb2-6e31a0763ed6)

**Abejorro Digital: Tipografía** es una aplicación web interactiva desarrollada para la visualización y exploración de fuentes tipográficas de Google Fonts en tiempo real. Constituye una herramienta ideal para diseñadores y desarrolladores que necesitan comparar cómo luce un texto o frase específica en distintas tipografías antes de implementarlas en sus proyectos.

## ✨ Características Principales

*   **Previsualización en Tiempo Real:** Escribe cualquier palabra o frase y observa de inmediato cómo se renderiza en múltiples tipografías simultáneamente.
*   **Selección Personalizada:** Un panel de configuración dedicado te permite elegir y modificar hasta 12 fuentes diferentes desde un catálogo extenso de Google Fonts.
*   **Exportación a PNG:** Descarga fácilmente la tarjeta de previsualización de la tipografía elegida como una imagen PNG de alta calidad, ideal para presentaciones o moodboards, gracias a la integración con `html-to-image`.
*   **Enlaces Directos:** Cada tarjeta de tipografía incluye un acceso directo a la página oficial de la fuente en Google Fonts para facilitar su adquisición o revisión de pesos adicionales.
*   **Interfaz Responsiva en Modo Oscuro:** Una interfaz moderna y adaptable construida con React, Tailwind CSS y Lucide React, ofreciendo una experiencia visual impecable en cualquier dispositivo.

## 🛠 Tecnologías Utilizadas

*   **Frontend:** React 19, TypeScript
*   **Estilos:** Tailwind CSS v4
*   **Herramientas & Bundler:** Vite
*   **Íconos:** Lucide React
*   **Utilidades:** html-to-image (para exportación de imágenes)

## 🚀 Ejecución Local

Sigue estos pasos para instalar y ejecutar el proyecto en tu entorno local:

**Requisitos previos:** Asegúrate de tener instalado [Node.js](https://nodejs.org/).

1.  **Clonar el repositorio y acceder a la carpeta:** (Si aplica)
2.  **Instalar las dependencias:**
    ```bash
    npm install
    ```
3.  **Ejecutar el servidor de desarrollo:**
    ```bash
    npm run dev
    ```
4.  La aplicación estará disponible usualmente en `http://localhost:3000` (o el puerto que indique la terminal).

## 📄 Scripts Disponibles

En el directorio del proyecto, puedes correr:

*   `npm run dev`: Inicia el entorno de desarrollo usando Vite.
*   `npm run build`: Construye la aplicación optimizada para producción.
*   `npm run preview`: Previsualiza localmente la versión construida de producción.
*   `npm run lint`: Ejecuta TypeScript para verificar errores de tipado sin emitir archivos compilados.
